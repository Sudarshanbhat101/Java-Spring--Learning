# Java Backend Learning Journey

This repository tracks my day-by-day Java practice as I prepare for a backend developer role. Each day contains small, focused programs and short concept notes.

## Purpose

- Build strong Core Java fundamentals.
- Practice object-oriented programming and problem-solving.
- Prepare for backend development using Java and Spring Boot.

## Current Focus

- Core Java fundamentals
- Collections (`List`, `Set`, `Map`), ordering (`Comparable`/`Comparator`), Stream API
- Daily consistency through GitHub streak commits

## Career Goal

My goal is to become a professional Java backend developer by building strong fundamentals first, then applying them in real backend projects using Spring Boot.

- Day 09: JVM stack/heap, reference vs object type, compile-time vs runtime polymorphism, String pool and immutability.
